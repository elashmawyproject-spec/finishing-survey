# حصر التشطيبات — Finishing Survey

تطبيق ويب (PWA) لرفع مقاسات التشطيبات من الموقع وتصدير جدول الكميات إلى Excel.

- يعمل من المتصفح ويُثبَّت على شاشة الجوال، ويعمل بدون إنترنت بعد أول فتح.
- عدة مشاريع؛ البيانات تُحفظ على الجهاز نفسه فقط.
- التصدير يملأ قالب BOQ المضمّن (الأرضيات، الحوائط، الفتحات، الوزرات، الأسقف، اللياسة، والملخصات).

لا يحتاج خادمًا: ملفات ثابتة فقط (`index.html`, `app.css`, `js/`, `sw.js`).
